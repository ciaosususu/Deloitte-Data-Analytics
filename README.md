# 📊 Deloitte Data Analytics Virtual Experience

This repository showcases my work from the Deloitte Data Analytics Virtual Experience on Forage.  
The project focuses on solving real-world business problems using data analysis, visualisation, and practical tools.


## 🚀 Project Overview

The repository is structured into multiple tasks, each addressing a different business scenario:

### 🔹 Task 1 – Telemetry Data Analysis
- Analysed machine telemetry data from 4 global factories
- Identified the factory with the highest downtime
- Determined the most failure-prone machine type
- Built visualisations using **Python** and **Tableau**

👉 **Key Insight:**  
- Factory with highest downtime: **Seiko (Osaka, Japan)**  
- Most problematic machine: **LaserWelder**


### 🔹 Task 2 – Gender Pay Equality Analysis
- Analysed employee compensation data
- Engineered a classification system for equality levels
- Visualised distribution of pay inequality

👉 **Key Insight:**  
- A significant portion of roles fall into **Unfair** or **Highly Discriminative** categories  
- Indicates potential gender pay imbalance requiring further investigation
